# Strukt Tasker — Changelog

Every change to this package is recorded as its own markdown file in this
directory. This README is the index; keep it newest first.

- Each change lives in `<version>-<slug>.md`, where `<version>` is the version
  the change ships in (use the next planned version for unreleased work) and
  `<slug>` is a short kebab-case description.
- Add the change file and a row in the index below.
- Each change file states what changed, why, the documentation touched, the
  tests covering it, and any public API impact.
- The versions listed here should match `Tasker::VERSION` on release.
