# 3.0.1 — Task composes Strukt\Event

**Date:** 2026-10-10

**Changed**

- `Strukt\Task` now composes `Strukt\Event` instead of reimplementing callable
  handling. `Task` holds a `private Event $event`; `callback()` returns
  `$this->event->ref()->getClosure()`, `reflection()` returns
  `$this->event->ref()`, and `invoke()` validates positional argument counts
  and then executes through `$this->event->applyArgs($arguments)->exec()`.
  `description()` and `parameters()` read their metadata through `ref()`.
- Removed the duplicated `Closure::fromCallable()` conversion and
  `ReflectionFunction` construction that previously lived in `Task`.

**Why**

- `strukt/tasker` required `strukt/event` but never used it. `Task` duplicated
  the `Strukt\Event` abstraction — a retained closure, its reflection, and
  argument application — leaving `strukt/event` an orphaned dependency. `Task`
  now builds on the event package, so the dependency is load-bearing.

**Docs**

- `README.md`: the Task API section and the `strukt/event` note now describe the
  composition, and the performance note credits `Strukt\Event`.

**Tests**

- `tests/Unit/TaskerTest.php`: added assertions covering `Task::callback()`
  (returns a `Closure`) and `Task::reflection()` (returns a
  `ReflectionFunction`).

**API impact**

- None. `Task`'s public surface and behavior are unchanged (6 tests,
  33 assertions pass).
